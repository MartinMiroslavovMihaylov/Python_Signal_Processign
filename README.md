# About the Repository

This repository contains Python scripts with functions for processing and analyzing raw measurement and simulation data, including S-parameters, time-domain signals, frequency-domain signals, and FFT data.

The provided tools allow you to perform a variety of signal processing and RF/microwave analysis tasks.

## Features

The repository includes functions to:

- Compute the Fast Fourier Transform (FFT)
- Extract first and third harmonics (fundamentals)
- Extract all higher-order harmonics excluding the fundamental
- Calculate Total Harmonic Distortion (THD)
- Calculate Signal-to-Distortion Ratio (SDR)
- Evaluate maximum current metal density for IHP technologies (G2, G3, G2Cu, G3Cu)
- Convert a 4-port DUT into an equivalent 2-port representation and plot S-parameters
- Calculate characteristic impedance of a function
- Compute group delay from S-parameters
- Calculate stability factors (μ and μ') from S-parameters
- Determine and plot the 1 dB compression point
- Generate eye diagrams
- Import and prepare data from `.csv` files for plotting
